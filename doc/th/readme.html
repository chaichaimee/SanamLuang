SanamLuang

ส่วนเสริมสำหรับโปรแกรมอ่านหน้าจอ NVDA
ช่วยแก้ไขข้อผิดพลาดการอ่านข้อความภาษาไทยที่พบบ่อย

ผู้พัฒนา : ชัย ไชยมี (Chai Chaimee)

ที่เก็บโครงการ : https://github.com/chaichaimee/SanamLuang

คำอธิบาย

สนามหลวง เป็นส่วนเสริม (add-on) สำหรับโปรแกรมอ่านหน้าจอ NVDA ที่ช่วยแก้ไขปัญหาการอ่านข้อความภาษาไทยผิดพลาด ซึ่งเกิดขึ้นบ่อยครั้งจากหลายสาเหตุ ได้แก่

  • การพิมพ์ภาษาไทยไม่ถูกต้องตามหลักภาษา (พบมากในคนรุ่นใหม่)
  • การพิมพ์ด้วยเสียง (speech-to-text) ที่ผิดพลาด
  • การเลือกคำอัตโนมัติ (auto-correct) ที่ทำให้สะกดคลาดเคลื่อน
  • ผลการสแกนด้วย OCR ที่วางตำแหน่งสระ วรรณยุกต์ และเครื่องหมายต่าง ๆ ผิดตำแหน่ง
ปัญหาเหล่านี้ทำให้เครื่องสังเคราะห์เสียง (synthesizer) อ่านภาษาไทยผิดเกือบทั้งหมด

ปุ่มลัด (Hotkeys)

NVDA+Shift+F4 → เปิดหน้าต่างตั้งค่า SanamLuang
NVDA+Shift+F4 (ขณะที่เลือกข้อความหรือคลุมดำทั้งเอกสาร) → แก้ไขข้อความที่ผิดทั้งหมดให้ถูกต้องตามอัตโนมัติ
กด NVDA+Shift+F4 เร็ว ๆ 2 ครั้ง → เปิด/ปิด โหมดการอ่านคำผิดของสนามหลวง

การทำงานของส่วนเสริม

เมื่อติดตั้งส่วนเสริม SanamLuang แล้ว จะเริ่มทำงานทันที โดยจะอ่านสระและวรรณยุกต์ที่อยู่ตำแหน่งผิดตามที่กำหนดไว้ในพจนานุกรมเริ่มต้น

ผู้ใช้สามารถเพิ่มคำที่สะกดผิดหรือตำแหน่งสระ/วรรณยุกต์ที่ต้องการแก้ไขได้เอง ผ่านหน้าต่างตั้งค่า (กด NVDA+Shift+F4) ซึ่งทำงานคล้ายพจนานุกรมการออกเสียงของ NVDA

หากต้องการปิดการทำงานของสนามหลวงชั่วคราว ให้กด NVDA+Shift+F4 เร็ว ๆ 2 ครั้ง จะได้ยินเสียงแจ้งว่า “สนามหลวง ปิด” และการอ่านจะกลับไปเป็นแบบมาตรฐานของ NVDA

กรณีเอกสารที่ผ่านการสแกน OCR

สำหรับเอกสารที่ได้จากการสแกน (OCR) ซึ่งมักมีปัญหาสระ วรรณยุกต์ ผิดตำแหน่ง เช่น

ํา    ํ่า    ํ้า    เเ    ฯลฯ

เพียงเลือกข้อความทั้งหมด (Ctrl+A) แล้วกด NVDA+Shift+F4 ส่วนเสริมจะทำการตรวจสอบและแก้ไขตำแหน่งสระ วรรณยุกต์ที่ผิดให้ถูกต้องทั้งเอกสาร โดยอัตโนมัติ (เฉพาะรายการที่กำหนดไว้ในพจนานุกรมของสนามหลวงเท่านั้น – ผู้ใช้สามารถเพิ่มเติมได้เอง)

ช่วยประหยัดเวลา ไม่ต้องแก้ทีละตำแหน่งด้วยตัวเอง

ประโยชน์เพิ่มเติม

นอกจากการแก้ไขเอกสารทั่วไปแล้ว สนามหลวงยังช่วยปรับการอ่านข้อความภาษาไทยแบบที่นิยมใช้ในโซเชียลมีเดีย ซึ่งมักมีการสะกดเปลี่ยนรูปเพื่อหลีกเลี่ยงการตรวจจับ เช่น

  • เงิu → เงิน
  • เvมร / เขมs → เขมร
  • และการสะกดหลบอื่น ๆ อีกมากมาย

ทำให้เครื่องสังเคราะห์เสียงสามารถอ่านข้อความเหล่านี้ได้ถูกต้องมากขึ้น แม้จะอยู่ในสภาพ “สนามรบทางภาษาไทย” ที่มีความซับซ้อนและรุนแรงขึ้นเรื่อย ๆ จากการสื่อสารออนไลน์ในปัจจุบัน
